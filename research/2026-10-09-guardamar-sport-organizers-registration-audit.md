# Guardamar sports organizers: registration-source audit — 2026-10-09

> Status: **open research / read-only public-source assessment**. No source adapter, runtime state, cron, production deployment or Telegram publication has changed. Resume here and in `research/2026-10-09-guardamar-running-events-registration.md`. Source observations are public web, **not** verified Termux HTTP or live production state.

## Question and operator's publication gate

Find first-party organizers/platforms that can reliably **prove a currently actionable registration** to a sporting event physically held in Guardamar del Segura, Spain, without a browser/daemon and without announcing mere calendar reservations.

**Strict rule** (operator, 2026-10-09): no advance **participation-registration announcement** from date/price/calendar alone. Evidence must belong to the same event **and edition** and show an actionable open form, or explicit organizer-sanctioned enrollment via contact with a valid time window. General contact email ≠ registration. A mere `Abierta` describing a competition format ≠ inscriptions open. Existing ordinary Tomorrow/Weekend/Sports Today calendar surfaces remain a separate product decision. Once rooted, all updates use shared EventAccess v3.

Work under `AGENTS.md`, KB 00–04, ADR 0100, ADR 0089–0092/0103. One normalized Event stream + optional source-owned EventAccessRecord, no extra sports engine, service, browser, AI classifier, runtime scraping registry or per-sport cron.

## Milestone B — immediate useful conclusions

1. **Strong P0 potential registration announcement**: Christmas chess 2026 on organizer's own Promochess shop, **not running**. Under operator policy, first run production-safe preview, validate actual same-year shop availability/organizer instructions, confirm it was not already posted, then consider an explicit publication. No automatic send now.
2. **Second strong future access candidate**: 2027-04-18 VIII Open Esphouses in Guardamar. A *dedicated* organizer signup product with tariffs for this exact stage has been verified separately from the calendar. Test action/availability and deduplication first; calendar label `etapa abierta` would not suffice by itself.
3. **Cross 2026**: priority still to obtain actual delegated signup form or event-specific organizer instructions; price calendar is insufficient.
4. **Club Tenis de Mesa**: add to next source recon list because its public registration via direct event-specific phone differs from sports federations. Verify direct authoritative post, calendar, frequency and whether local fixture really hosted in Guardamar.
5. **Anti-false-positive**: distinction between `inscripciones abiertas` (live participant access), `etapa abierta` (open tournament type), `inscripción abierta` generic badge (may be stale), and an *inactive, still-accessible registration URL*.
6. **Authority conflicts**: use year-matched organizer/product/effective-action facts, flag stale `2025` text on 2026 Promochess article; don't silently normalize it to 2026 in dates of **opening/closing**. Check more current source before announcing deadline.
