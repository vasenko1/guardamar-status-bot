# Architecture Decision Records

Use this directory for durable decisions that affect architecture, runtime
cost, dependencies, data handling, or feature boundaries.

## Suggested filename

`NNNN-short-decision-title.md`

## ADR template

```markdown
# NNNN: Decision title

- Status: Proposed | Accepted | Superseded
- Date: YYYY-MM-DD

## Context

What constraint or problem requires a decision?

## Decision

What was decided?

## Consequences

- Benefits
- Costs and tradeoffs
- Follow-up work

## Alternatives considered

- Alternative and reason it was not selected
```

After accepting an ADR, add it to `docs/kb/10_Decision_Log.md` and update any
affected knowledge-base pages.
